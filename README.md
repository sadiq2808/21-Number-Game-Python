## 🎮 21 Number Game

A simple 21 Number Game built with Python, where the player competes against the computer by entering consecutive numbers.

## About the Project

This is a beginner-friendly Python console game created to practice fundamental programming concepts such as:

- Variables
- Functions
- if / elif / else
- while loops
- for loops
- Lists
- User input
- Conditional logic
- Basic game logic



## Game Rules

The game is played between two players who take turns one after another.
On each turn, a player can call 1 to 3 numbers.
The numbers must be consecutive (for example, 5 6 7) skipping numbers leads to disqualification.
The counting always starts from 1 and continues upward.
The one who calls 21, loses the game.
